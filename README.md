# TalosDesk

**Windows 本地项目运行工作台：保存项目命令，一键运行，集中查看状态与日志。**

中文全称：TalosDesk 本地项目运行管理软件。

## 用途

在多个本地开发项目之间切换时，启动、测试和检查命令容易遗忘，工作目录也可能不同。
TalosDesk 将这些操作保存为可查看、编辑、复制和执行的配置，帮助用户减少查找命令和切换终端的操作。

典型使用流程：

```text
选择项目 → 选择已确认的命令 → 运行 → 查看输出和结果 → 按需停止或重启
```

## 已确认的首版方向

- Windows 独立桌面应用；单用户，管理本地项目。
- 保存项目目录，以及启动、测试、检查等命令的名称、用途、工作目录和运行类型。
- 支持持续运行的服务，以及执行后结束的任务；首版命令无需中途输入。
- 单条命令可运行、停止、重启；也可勾选当前项目中的多条命令，同时启动尚未运行的命令，并分别查看输出和结果。
- 切换项目不停止正在运行的任务；各命令输出分别展示。
- 命令可编辑、复制、删除，并通过上移、下移调整保存顺序；配置支持保存、导入和导出。
- 首版手动配置或导入。Agent 可在用户授权后整理已有项目的配置，由用户确认再导入。
- 关闭应用时若仍有任务运行，提示“停止任务并退出”或“返回应用”。

首版目前支持项目和命令管理、运行/停止/重启、勾选多条命令同时运行、实时标准输出与错误输出、状态结果、本地配置保存，以及 JSON 导入导出。主窗口左侧保留项目列表，右侧分为项目概览、命令管理和运行输出三页；启动进入项目概览，切换项目时保持当前页面。命令管理页选中命令用于单条操作，勾选命令用于批量启动；成功启动后自动打开运行输出页，该页可切换查看当前项目各命令的状态与日志。已运行的命令会在批量启动时跳过。命令列表按像素滚动，便于在多条命令中逐步定位。删除命令前会确认，运行中的命令须先停止；顺序调整和删除会立即保存，保存失败时恢复原状。导入前可预览；重复项目和命令逐项选择保留或替换；导入内容不会自动执行。自动识别命令及后台托盘运行留待试用后另行评估。

## 技术方向

C# / .NET 10 / WPF / 本地 JSON 配置。仓库以 `global.json` 锁定 .NET SDK 10.0.401。C# Dev Kit 直接打开解决方案时需要系统可发现该 SDK；本机已通过官方安装包安装到标准目录。其他隔离环境可运行 `pwsh -NoProfile -File .\scripts\Install-Sdk.ps1` 安装仓库本地 SDK，再运行 `pwsh -NoProfile -File .\scripts\Test-Environment.ps1` 检查环境；本地 CLI 命令通过 `scripts/With-Sdk.ps1` 使用它。

目标交付方式为包含 .NET 运行时的 Windows x64 发布包。目标项目所需的 Go、Python、uv 等工具仍需在本机准备。
核心功能本地运行，不依赖模型 API。进程由 PowerShell 7 执行，并通过 Windows Job Object 管理归属进程；自动化测试使用合成命令，真实项目兼容性仍需试用。

## 运行与发布包

包含三页改动的最新本地预览包位于 `artifacts/TalosDesk-win-x64-three-page-review.zip`，对应的发布目录为 `artifacts/publish/three-page-win-x64`；桌面上的 `TalosDesk.lnk` 已指向该目录中的程序。此前的预览包 `artifacts/TalosDesk-win-x64-review.zip` 和更早的验证包 `artifacts/TalosDesk-win-x64.zip` 仍保留。解压预览包后运行 `TalosDesk.App.exe`；包内包含 .NET 和 Windows Desktop 运行时，不需要另装 .NET SDK 或运行时。程序与窗口均使用原创的二次元游戏风格抽象图标。该包是便携发布目录，不是安装程序，也不是正式发布版本。

运行已配置命令需要在启动 TalosDesk 前安装 PowerShell 7，并确保 `pwsh.exe` 位于应用可见的 `PATH` 中。Go、Python、uv 等项目工具不包含在 TalosDesk 包内，也需自行准备并放入应用启动时继承的环境。工作区配置保存在 `%LOCALAPPDATA%\TalosDesk\workspace.json`；应用不会因启动而自动运行已保存命令。

当前只在本机 Windows x64 环境验证过预览包启动；最低支持 Windows 版本尚未确认。2026-09-26 在隔离工作区对当时的界面完成合成命令运行、服务重启与停止、项目和命令编辑、项目切换、配置导出及导入回归，并重测保存失败回滚、损坏配置提示和导入冲突选择；导入后没有自动执行命令，真实工作区配置未被测试修改。2026-09-27 三页界面在隔离副本中完成命令可见数量、滚动、单条与批量运行跳转、日志和项目切换检查；新的自包含发布目录通过桌面快捷方式启动，确认三页导航和默认项目概览可见，真实工作区配置哈希未变。便携 ZIP 尚未在另一台机器上验收。
