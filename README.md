# TalosDesk

**Windows 本地项目运行工作台：保存项目命令，一键运行，集中查看状态与日志。**

中文全称：TalosDesk 本地项目运行管理软件。

> 当前状态：已具备首个可运行开发版本，正在收尾自动化验证与桌面试用；尚未发布安装包。
> 本地 Git 和 [GitHub 私有仓库](https://github.com/kongerly/TalosDesk) 已准备。开发机已在仓库内和系统 SDK 目录安装并验证 .NET SDK 10.0.401。

## 用途

在多个本地开发项目之间切换时，启动、测试和检查命令容易遗忘，工作目录也可能不同。
TalosDesk 将这些操作保存为可查看、编辑、复制和执行的配置，帮助用户减少查找命令和切换终端的操作。

典型使用流程：

```text
选择项目 → 选择已确认的命令 → 运行 → 查看输出和结果 → 按需停止或重启
```

## 已确认的首版方向

- Windows 独立桌面应用；单用户，管理本地项目。
- 保存项目目录，以及启动、测试、检查等命令的名称、用途、工作目录和运行类型。
- 支持持续运行的服务，以及执行后结束的任务；首版命令无需中途输入。
- 运行、停止、重启，实时查看各命令的输出和执行结果。
- 切换项目不停止正在运行的任务；各命令输出分别展示。
- 命令可编辑、复制；配置支持保存、导入和导出。
- 首版手动配置或导入。Agent 可在用户授权后整理已有项目的配置，由用户确认再导入。
- 关闭应用时若仍有任务运行，提示“停止任务并退出”或“返回应用”。

首版目前支持项目和命令管理、运行/停止/重启、实时标准输出与错误输出、状态结果、本地配置保存，以及 JSON 导入导出。导入前可预览；重复项目和命令逐项选择保留或替换；导入内容不会自动执行。自动识别命令及后台托盘运行留待试用后另行评估。

## 技术方向

C# / .NET 10 / WPF / 本地 JSON 配置。仓库以 `global.json` 锁定 .NET SDK 10.0.401。C# Dev Kit 直接打开解决方案时需要系统可发现该 SDK；本机已通过官方安装包安装到标准目录。其他隔离环境可运行 `pwsh -NoProfile -File .\scripts\Install-Sdk.ps1` 安装仓库本地 SDK，再运行 `pwsh -NoProfile -File .\scripts\Test-Environment.ps1` 检查环境；本地 CLI 命令通过 `scripts/With-Sdk.ps1` 使用它。

目标交付方式为包含 .NET 运行时的 Windows x64 发布包。目标项目所需的 Go、Python、uv 等工具仍需在本机准备。
核心功能本地运行，不依赖模型 API。进程由 PowerShell 7 执行，并通过 Windows Job Object 管理归属进程；自动化测试使用合成命令，真实项目兼容性仍需试用。
