TalosDesk v0.3.1-rc.1 预览候选版（尚未正式发布）
======================

系统范围：Windows 11 x64
运行方式：解压全部文件后运行 TalosDesk.App.exe

发布包已经包含 .NET 10 和 Windows Desktop 运行时，不需要安装 .NET SDK。
运行项目命令前必须安装 PowerShell 7，并确保 pwsh.exe 位于应用可见的 PATH 中。
项目自身使用的 Go、Python、uv 等工具仍需单独安装。

快速开始：
1. 解压全部文件，运行 TalosDesk.App.exe。
2. 点击“＋ 添加项目”，选择项目目录；也可以点击“导入”并先查看 JSON 预览。
3. 进入“命令管理”，点击“＋ 添加命令”，填写名称、用途、命令和工作目录。
4. 选择命令后点击“运行”；在“运行输出”查看 stdout、stderr、状态和退出结果。
5. 服务命令可持续运行，验证完成后点击“停止”。TalosDesk 只停止本次启动且能确认归属的进程。

导入示例只会保存配置，不会自动运行命令或安装依赖。

工作区配置保存在：
%LOCALAPPDATA%\TalosDesk\workspace.json

同一个工作区只会打开一个 TalosDesk 窗口；重复启动会在没有命令运行或保存操作时重新加载配置并唤醒已有窗口。
窗口侧栏显示当前工作区身份和实际配置路径。若配置文件被外部程序修改，应用会停止保存并提示重新打开，避免覆盖新内容。

隐私提示：
- 项目路径、命令、用途和普通环境变量会以明文保存在工作区与导出文件中。
- 显式标记的敏感环境变量在本机使用 Windows DPAPI CurrentUser 保护；分享导出只保留变量名和待填写状态。
- 不要把密码、令牌或 API 密钥直接写入命令或普通变量。分享导出文件前仍需检查其中的明文字段。
- 新运行会在实时显示、内存和磁盘日志前遮蔽本次已知的非空敏感值及有限令牌模式；既有日志不会自动改写。
- “关于与更新”中的检查默认关闭；手动检查或明确开启后只读取官方 GitHub Releases 元数据，不上传工作区、命令、日志或凭据。
- 本地崩溃诊断默认开启，只保存最小结构信息到工作区旁文件，不保存异常消息或命令输出，也不自动上传；磁盘时间保持 UTC，界面按当前 Windows 本地时区显示；可在“关于与更新”页关闭、查看和清理。

手工升级：
1. 从“关于与更新”页打开官方发布页，下载完整便携包及 SHA-256 文件并核对校验值。
2. 停止命令、退出 TalosDesk，并备份本机工作区及需要保留的日志、位置记录、更新状态、诊断设置和崩溃记录。可分享导出不含敏感值，不能代替完整备份。
3. 将新包解压到新的应用目录，再以同一明确的 --workspace 路径启动。不要覆盖正在运行的程序。
回退旧包时必须使用旧版兼容的工作区副本，避免旧程序覆盖较新 schema。

运行日志：
- 默认位于工作区文件旁的 <工作区文件名>.logs，也可在输出页选择其他父目录。
- 标准输出和诊断输出按纯文本捕获；PowerShell ANSI 样式不会写入界面或日志。
- 每个工作区默认最多保存 500 MB、保留 30 天；输出页显示实际路径并可清理已结束批次。
- 更改日志位置时会迁移当前工作区历史日志；若提示旧目录残留，需要手工检查并清理该路径。
- 自动重启每次成功创建都建立独立日志批次；等待保留上一失败批次，恢复状态不写入 stdout/stderr 或历史结果。

已知限制：
- 本包为本机候选，尚未正式发布；未执行干净 Windows 11 客户端、系统级丢包下的挂起连接、多屏/DPI 实机、真实托盘鼠标点击与资源管理器重建通知区域验收。验收记录位于源码 docs/acceptance-v0.3.1-rc.1.md，不把旧版验收作为本包证据。
- 工作区保存升级为 schema 5；兼容读取 schema 1–4，读取不改写，保存才升级。旧应用拒绝 schema 5，回退须使用兼容副本；schema 4 TCP 保留，旧配置默认关闭自动重启。
- 服务可选开启非零退出后自动重启，默认关闭；仅独立运行（含勾选批量）生效，分组不生效。每轮最多追加 3 次，分别等待 2/4/8 秒；运行时长或 TCP 通过不重置次数。退出 0、业务挂起、TCP 失败不会触发。
- 停止会取消等待；退出确认期间暂停自动提交，返回保留原期限和预算，确认退出先取消轮次再停止归属进程，不等待退避到期。关闭后不恢复重试队列。
- 导入先展示策略预览，不自动运行命令或连接探测端口；应用启动、恢复和唤醒也不自动运行已保存命令。
- 服务可选本机 TCP 探测，默认间隔 2 秒、连接超时 1 秒、启动等待 120 秒、连续失败阈值 3 次。
- TCP 通过不证明业务健康或监听者归属；仅连接所选 127.0.0.1 或 ::1 端口，不发送业务数据。失败不停止或重启命令，超时后可恢复，探测结果不保存到历史日志。
- 仅支持无需中途输入的非交互命令。
- 命令编辑器可补全本地路径、PATH 中的程序和环境变量，但不会执行输入内容，也不是交互终端。
- “运行中”只表示进程仍存在，不表示对应服务已经就绪。
- 界面只显示每个通道最近 10,000 行；磁盘日志按容量和期限保存。
- DPAPI CurrentUser 密文不能作为跨账户或跨设备凭据格式，导入后的待填写项需要重新录入。
- 本版没有代码签名，Windows 可能显示信誉或安全提示。
- 这是便携包，不是安装程序。
