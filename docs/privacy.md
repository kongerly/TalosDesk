# TalosDesk 隐私说明

TalosDesk 在本机管理工作区、命令和日志，不提供账号或云同步，不收集产品遥测。本文描述当前源码；已发布版本的功能差异见[版本记录](changelog/README.md)。

## 本机数据

默认工作区为 `%LOCALAPPDATA%\TalosDesk\workspace.json`。下表的 `<工作区>` 表示完整工作区文件路径，例如 `C:\Example\workspace.json`；指定 `--workspace` 时所有旁文件均随该路径隔离，不进入配置导入导出。

| 数据 | 位置 | 内容、保留与清理 |
| --- | --- | --- |
| 工作区 | `<工作区>` | 路径、命令、用途、分组和普通变量为明文；显式敏感变量使用 DPAPI。用户自行备份，关闭后可删除 |
| 运行日志 | `<工作区>.logs`，或用户选择位置下的工作区专属目录 | stdout/stderr、批次元数据及设置为明文；默认 500 MB、30 天，输出页可调整、清理已结束批次和打开实际目录 |
| 日志位置记录 | `<工作区>.log-location.json` | 本机日志目录；关闭应用后可删除，恢复默认位置 |
| 窗口状态 | `<工作区>.window-settings.json` | 尺寸、屏幕、位置与最大化状态；正常退出更新，关闭后删除恢复默认布局 |
| 更新偏好 | `<工作区>.update-settings.json` | 开关、渠道、跳过版本和稍后期限；关闭后删除恢复默认关闭及跟随当前版本渠道 |
| 更新缓存 | `<工作区>.update-cache.json` | 检查时间、限流、ETag、分页及必要发布投影，不存原始响应或正文；关闭后删除，下次检查重新获取，不重置偏好 |
| 崩溃诊断 | `<工作区>.crashes` | 版本、平台、异常来源/类型、错误码及无源码路径的结构化堆栈；最多 100 条、5 MiB、30 天，可在“关于与更新”页清理 |
| 诊断设置 | `<工作区>.diagnostics-settings.json` | 诊断默认开启，关闭仅影响后续采集；关闭应用后删除恢复默认开启 |

运行日志可迁移位置，须先停止命令并取消待重试。迁移后提示旧目录残留时需手工清理；“清空显示”不删除磁盘日志，删除命令也不会立即删除历史文件。损坏元数据的历史批次仍计入容量并可清理，活动批次不会被自动删除。

诊断不保存异常消息、命令、输出、环境变量或凭据，不生成内存转储、不自动上传。记录时间为 UTC，界面按 Windows 本地时区显示。损坏记录不展示原文，仍计入容量；诊断设置不可读时保留原文件并停止采集。强制结束、断电、栈溢出、严重资源故障和文件系统阻塞可能无法留下记录，应用不控制 Windows 自身错误报告。

## 明文、加密与分享

- 不要把密码、令牌或 API 密钥写进命令或普通变量。DPAPI `CurrentUser` 仅保护显式敏感变量，不能抵御同一 Windows 用户权限下的程序，也不能作为跨账户或跨设备凭据格式。
- 每次启动前解密并只注入本次目标进程，编辑器不回填已保存明文。待填写或不可解密时阻止启动，保留原数据。
- 可分享导出会移除所有敏感明文与本机密文，只保留变量名和待填写状态；其他字段仍是明文，分享前须人工检查。导出不能替代完整本机备份。
- 导入先预览，确认后只保存，不自动执行或探测。当前源码保存 schema 5，旧版回退需使用兼容副本。
- 新输出先遮蔽本次已知非空敏感值及有限令牌模式，再进入界面、内存、复制和磁盘。旧日志、编码值、跨 stdout/stderr 拆分的值以及目标程序另写文件不在保证范围内。

自动重启仅保存服务开关；次数、截止时间和轮次仅在内存，不跨启动恢复、不进入导出。每次重试重新预检敏感变量，产生独立且仍为明文的日志批次，不额外保存秘密副本。完整行为见[设计说明](design.md#有限自动重启)。

## 联网行为

| 功能 | 触发条件与请求范围 |
| --- | --- |
| TCP 探测 | 服务开启探测且实际运行后，仅连接 `127.0.0.1` 或 `::1` 的所选端口；不解析域名、不发业务数据，监听者可能记录连接。结果仅在内存，连通不证明健康或归属 |
| 更新检查 | 默认关闭；手动操作或此前开启的下次启动检查读取 `api.github.com` 上官方 `kongerly/TalosDesk` Releases 元数据及合法同源分页 |
| 发布页 | 用户点击后通过默认浏览器打开校验过的官方 HTTPS 发布页；浏览器的登录状态、Cookie 和后续请求由浏览器及 GitHub 处理 |

打开更新页、切换渠道或本次开启不会发请求。自动检查距上次实际尝试至少 24 小时，持续打开不轮询；手动仍遵守节流和服务器限流。关闭自动不删除既有记录，也不取消已由用户手动接管的请求。

更新使用系统代理和正常 TLS，发送固定产品标识、API 头、分页参数及可用 ETag，不携带 GitHub 凭据、Cookie、工作区、命令、日志、环境变量或持久设备标识。服务方及代理仍能看到出口 IP、时间和公开请求信息。错误只保存固定类别，不另存响应原文或代理信息。

应用不自行下载附件、执行安装脚本、替换程序或重启命令。偏好损坏时保留文件并关闭自动，手动检查仍可用；可关闭应用后保留并移走异常文件再打开。写入失败时本会话设置仍生效，界面提示重启后可能恢复旧设置。

构建、依赖还原、Git 操作及用户命令可能另行联网，其目标和凭据由对应工具决定。未来若引入遥测，须默认关闭、说明字段和目的，并以 `DO_NOT_TRACK=1` 覆盖开启选项。

## 发布与反馈

发布包不得包含真实工作区、日志、凭据或本机测试资料。反馈缺陷前请检查附件并脱敏，避免附上完整配置或输出。SHA-256 只验证文件完整性，不能替代发布者签名；当前运行时安全状态见[安全维护说明](security-maintenance-2026-10-22.md)。
