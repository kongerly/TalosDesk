# TalosDesk 隐私说明

本说明适用于当前开源桌面应用及当前开发分支。TalosDesk 在本机管理工作区、命令和运行日志，不提供账号或云同步，也不收集产品遥测。

## 本机数据

| 数据 | 默认位置 | 内容与保护 | 保留和清理 |
| --- | --- | --- | --- |
| 工作区 | `%LOCALAPPDATA%\TalosDesk\workspace.json` | 项目路径、命令、用途、分组和普通环境变量为明文；显式敏感环境变量使用 Windows DPAPI `CurrentUser` 保护 | 用户可在应用关闭后删除；导出文件由用户选择位置并自行管理 |
| 运行日志 | 工作区文件旁的 `<工作区文件名>.logs`，或用户选择位置下的工作区专属目录 | `stdout.log`、`stderr.log`、`run.json` 和 `settings.json` 均为明文；新运行会在写入前遮蔽本次已知的敏感值和有限令牌模式 | 默认上限 500 MB、保留 30 天；可在输出页修改、清理已结束批次或打开实际目录手工删除 |
| 日志位置记录 | 工作区文件旁的 `<工作区文件名>.log-location.json` | 保存当前工作区选择的日志目录，不随工作区导入导出 | 恢复默认日志位置后不再需要；应用关闭后可手工删除 |

指定 `--workspace <文件>` 时，工作区、默认日志和位置记录都归属于该文件。隔离测试应传入独立路径，避免读取或修改正式数据。

TalosDesk 当前不生成崩溃转储或诊断上报文件。未来若增加本地诊断，必须在发布前说明实际位置、字段、保留和清理方式，并复用敏感输出的保护边界。

## 明文、加密与导入导出

- 命令文本、项目路径、用途、分组和普通环境变量是明文。请勿把密码、令牌或 API 密钥写入这些字段。
- 敏感环境变量只在本机工作区保存 DPAPI `CurrentUser` 密文；运行目标进程前才解密，并只注入该次进程环境。此保护不能抵御同一 Windows 用户权限下的其他程序，也不能作为跨账户或跨设备凭据格式。
- 可分享导出会把所有敏感项改成待填写状态，并移除本机密文。其他字段仍是明文，分享前需要人工检查。
- 导入会先显示完整预览，不会自动执行命令。待填写或不可解密的敏感项会阻止依赖它的命令启动。
- 既有日志不会自动重写。新的输出脱敏覆盖本次运行已知的非空敏感值及有限令牌模式；编码后的值、拆到 stdout/stderr 两个通道的值，以及目标程序自行写入其他文件的内容不在保证范围内。

## 联网行为与遥测

TalosDesk 当前开发分支提供用户主动控制的更新检查，没有账号、云同步、遥测或自动上传功能。更新检查默认关闭；打开“关于与更新”页或切换渠道不会发起请求，手动检查及用户已开启的下次启动检查会访问下述固定更新源。仓库的构建、依赖还原、CI、Git 操作和用户保存的命令也可能访问网络，其目标、内容和凭据由对应工具或命令决定，不由 TalosDesk 代为审查。

如果未来增加遥测，必须默认关闭，明确展示采集字段和目的，并允许用户关闭；`DO_NOT_TRACK=1` 必须覆盖应用内的开启选项。相关实现需要有不发送请求的自动化测试，隐私说明也必须在发布前同步更新。

## v0.2.0 T07 更新检查

当前开发分支已经接入桌面入口、自动启动调用和设置页面；完整行为及验收条件见 [设计说明的 T07 章节](design.md#t07v020-更新检查契约已实现)。

### 请求与用户选择

更新检查默认关闭。用户可以手动检查，或开启“启动时检查更新”，从下次启动开始在后台检查；开启后也可随时关闭。自动检查距上次实际尝试至少 24 小时，应用持续打开时不定时轮询。页面会说明设置只属于当前工作区；手动检查可在自动关闭时使用，但仍遵守最短请求间隔和服务器限流。

应用仅匿名读取 `api.github.com` 上 `kongerly/TalosDesk` 仓库的公开 Releases 元数据及经过校验的同一接口分页地址，采用系统代理和正常 TLS 校验。请求包含固定产品标识 `TalosDesk`、API 格式/版本头、分页参数及已有缓存的 ETag；不携带 GitHub 登录令牌或 Cookie，不发送工作区路径、项目、命令、日志、环境变量、凭据或持久设备标识。联网仍会让服务方及相关网络代理看到出口 IP、请求时间和公开请求信息，因此不将“无用户数据上传”描述为完全匿名不可观察。

只在用户点击“查看发布页面”时，通过默认浏览器打开经过校验的官方仓库 HTTPS 发布页；浏览器可能使用自己的登录状态、Cookie，并请求页面资源，其联网行为由浏览器和 GitHub 处理。TalosDesk 不内嵌页面、不加载发布正文的图片，不自行下载附件、执行安装脚本、替换应用或重启命令。离线、限流和检查失败只影响更新结果，不影响命令运行。

### 本机记录与清理

| 更新状态文件 | 位置 | 内容与保留 | 清理影响 |
| --- | --- | --- | --- |
| 更新偏好 | 工作区文件旁的 `<工作区文件名>.update-settings.json` | 明文保存自动开关、渠道选择、已跳过版本和“稍后”期限，保留到用户修改或删除 | 关闭应用后删除会恢复默认关闭及跟随当前版本渠道，并清除跳过/稍后记录 |
| 更新缓存 | 工作区文件旁的 `<工作区文件名>.update-cache.json` | 明文保存检查时间、限流期限、ETag、分页信息及最近完整发布列表的必要投影；不保存原始响应或发布正文。列表投影仅在完整成功后替换，失败仍更新尝试时间及限流记录 | 关闭应用后可删除，下次检查重新获取元数据；不会重置偏好 |

默认工作区的上述文件分别位于 `%LOCALAPPDATA%\TalosDesk\workspace.json.update-settings.json` 和 `%LOCALAPPDATA%\TalosDesk\workspace.json.update-cache.json`。指定 `--workspace <文件>` 时，两者只归属该隔离路径，不使用其他工作区的偏好或缓存，不进入工作区 JSON、导入导出、用户命令日志或发布包。默认关闭且未进行设置或检查操作时，不创建更新文件。

记录不包含凭据，但检查时间和跳过记录仍是本机使用信息。关闭自动检查不删除既有记录，也不取消已被用户手动检查接管的请求。检查错误使用固定类别，不另存响应正文、代理地址或底层异常原文；本功能不产生崩溃转储或诊断上传。

偏好文件损坏、不可读或格式不受支持时保留原文件，关闭自动检查并禁止直接覆盖；手动检查仍可用。页面将说明关闭应用后保留并移走异常文件、重新打开即可恢复。正常设置写入失败时，本次会话的选择仍生效，但会提示重启后可能恢复旧设置；缓存写失败不抹去本次检查结果。具体失败和恢复规则见设计契约。

这项请求只用于用户选择的更新检查，不增加产品遥测；上文关于未来遥测默认关闭和 `DO_NOT_TRACK=1` 的要求保持不变。

## 发布包

发布包不应包含真实工作区、用户日志、凭据或本机测试配置。发布页面会说明支持范围、代码签名状态和校验方式；SHA-256 校验值用于检查下载完整性，不能替代发布者签名。
