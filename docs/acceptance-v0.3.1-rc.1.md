## 解压 EXE 实际操作

使用中文和空格临时目录、独立工作区、合成 PowerShell 脚本及回环 TCP 端口，通过实际窗口操作执行。日志、界面文本、计数、PID 与清理证据保存在忽略目录 `artifacts/tests/rc1-package/`（`desktop-evidence.txt`、`desktop-results.json`、`cleanup-final.json`），不进入包或仓库。

| 场景 | 实际结果 |
| --- | --- |
| 无 SDK 路径启动与同工作区二次启动 | 自包含 EXE 打开窗口；第二实例退出 0 并激活首实例；空闲正常关闭退出 0，保存隔离窗口设置。 |
| 服务、TCP 与输出 | 合成服务监听成功，界面显示 TCP 探测通过、预算 0/3；stdout/stderr 分开显示，新会话写入独立日志批次。 |
| 并行成功任务 | 服务保持同一 PID 和探测通过；任务显示合成输出及退出码 0。 |
| 手动停止与重启 | 停止后原 PID 与监听端口释放，未自动启动；点击重启创建新 PID、新日志批次和探测周期，预算为 0/3。 |
| 非零退出、退避与耗尽 | 一轮连续四个会话失败，日志完成至下次开始的间隔为 2.012、4.011、8.012 秒；各次 TCP 通过不清零预算，最终显示耗尽 3/3。脚本内退出 19 经 PowerShell 包装命令返回 1，本轮记录实际退出码 1。 |
| 分组失败清理 | 独立服务已运行时启动三命令分组；独立服务被跳过，失败任务退出 7，分组新建服务停止并提示失败，独立服务的 PID、监听和预算保持不变。 |
| Ctrl+C 超时强停 | 另启动已安装忽略 Ctrl+C 处理器的合成服务，确认就绪后点击停止；最终显示已强制停止、退出码 1，目标 PID 释放，独立 TCP 服务继续运行。 |
| 确认期间到期与返回 | 运行时打开退出确认，再触发该服务失败；超过 2 秒截止时间仍未追加进程。点击返回后只追加一个会话，界面显示 1/3 并重新探测通过，未重置预算。 |
| 确认退出取消待重试 | 再次打开确认并触发失败，超过 4 秒截止时间仍停留在原计数；确认停止并退出后再等 9 秒，无新会话、无监听，应用退出。 |
| 重开不自动运行 | 重新打开同一隔离工作区，运行和待重试均为 0，服务计数未增加。 |
| 验收清理 | 本轮记录的 20 个合成服务 PID 均已退出，端口释放；最后一次原生文件对话框尝试结束后，核对 EXE 路径、启动时间且无子进程，结束该隔离实例。未按名称结束任何系统进程。 |

等待中的停止按钮尝试多次错过 2/4/8 秒窗口，未取得有效取消证据，不记通过。原生文件选择器已打开，但控件定位报 `element ... is not available in cached app state`，焦点定位也未能可靠进入文件名；没有打开其他目录文件或导入正式配置。本轮未取得 EXE 导入预览/确认的有效结果，标记文件不存在也不能作为导入不执行的完整验收。

## 未执行与限制

- 直接发布 EXE 的仅待重试状态下停止、手动重启及首次打开退出确认，原生文件选择器完成导入预览/确认，运行中强制结束发布 EXE 后的 Job 与历史中断检查，EXE 日志目录故障注入，仍未验收。对应包内程序集自动化已通过，不能替代这些实际 EXE 操作。
- 按用户此前要求，继续跳过干净 Windows 11 客户端、真实系统挂起连接、多屏与 Windows DPI 实机切换、真实托盘鼠标操作和资源管理器重建通知区域；本机隔离工作区、WPF 布局缩放和托盘替身不替代这些检查。
- Windows 10、跨账户 DPAPI、签名、安装程序与包管理器分发，本轮未验收。
- 真实 Windows 创建回滚失败仅用替身覆盖，未注入 Windows API 故障；同步创建进入串行提交后必须先返回并登记才能停止，不承诺中断创建本身。
- 自动重启只处理已启用的独立服务非零退出，每轮最多追加三次，等待 2/4/8 秒；运行或 TCP 通过不重置预算。退出 0、业务挂起、端口误归属、分组恢复和跨应用恢复不在范围内，历史日志不含恢复链字段。
- 无代码签名。有限恢复不扩大现有 Job 归属、DPAPI 与脱敏保护范围；保存最后校验到替换之间仍有设计说明所列的极短竞争窗口。

本轮全部命令、工作区、标记文件和监听端口均为独立临时目录中的合成数据，不读取或修改正式工作区；仅停止本次启动并确认归属的会话。
