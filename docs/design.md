# TalosDesk 设计说明

本文记录当前源码的行为契约。版本与交付状态见[路线图](roadmap.md)，数据位置与清理见[隐私说明](privacy.md)，检查方法见[测试说明](testing.md)。历史发布不自动具备当前源码能力。

## 产品与技术范围

TalosDesk 是单用户、Windows 本地的非交互命令运行工作台，核心流程为选择项目、运行命令、查看结果、停止或重启。采用 C#、.NET 10、WPF 和本地 JSON；PowerShell 7 由用户安装，核心运行不依赖后端或模型 API。SDK 与自包含运行时分别由 `global.json`、`eng/dotnet-sdk.json` 固定。

`TalosDesk.Core` 负责配置、进程、分组、日志、探测、恢复、更新和诊断；`TalosDesk.App` 负责 WPF 交互及 Windows 窗口、托盘和实例协调。编辑控件使用 AvalonEdit，第三方版本见项目文件及许可声明。

## 命令与进程

- 使用 `pwsh -NoProfile -NonInteractive -Command` 执行保存的命令，工作目录来自配置。编辑补全仅枚举目录、`PATH`、`PATHEXT` 和环境变量名，不执行内容或加载 profile。
- 根进程挂起创建，加入独立 Windows Job 后恢复执行；仅管理本次启动且能确认归属的进程，不按进程名批量结束。
- 停止先尝试 Ctrl+C，等待 5 秒后仍未退出则终止归属 Job 并确认结果。Ctrl+C 依赖控制台与目标处理器；宿主信号处理不能向后续命令传递忽略标记。
- 进程存活、TCP 可达、正常完成、非零失败、用户停止分别表示。stderr 是诊断通道，最终结果按退出状态判断；捕获前关闭 PowerShell ANSI 样式。
- 同一命令不能重复运行。创建回滚或观察失败时，未确认归属释放就保留占用和停止能力；`Completion` 完成或抛错不等于归属已释放。

## 分组执行

分组属于项目，同一命令可被多个分组引用，成员保存独立顺序。

| 模式 | 启动与结束规则 |
| --- | --- |
| 同时执行 | 按顺序发起空闲成员，跳过占用项；任务全部成功后可提示任务完成，但继续监视服务，直至本次成员全部结束 |
| 按成功顺序执行 | 仅允许任务，启动前预留全部成员；前项成功才启动下一项，失败、停止或启动失败终止队列 |

同时分组任一成员失败时，只停止本次启动且身份仍匹配的其他会话，不接管被跳过的独立服务、恢复轮次或后来新建会话。旧执行回调不得覆盖新执行。顺序队列活动时禁止修改或导入工作区；退出先取消未启动步骤，再停止归属会话。

多命令启动先对实际成员整体预检，已知配置错误时整批不启动；预检后的创建或执行失败仍按归属规则处理。预检本身不创建进程或日志批次。

## 工作区与保存

当前源码保存 schema 5，兼容读取 schema 1–4；读取不改写，下次成功保存才升级，旧应用拒绝不支持的 schema。schema 2 引入分组、3 引入环境变量、4 引入 TCP 探测、5 引入自动重启。示例见 [examples](../examples/README.md)。

- JSON 字段使用 PascalCase。所有对象拒绝未知字段、重复键、大小写变体、错误类型和非法必需值，以 `InvalidDataException` 表达；不静默丢弃字段或覆盖原文件。
- 项目与命令 ID 必须是非全零 GUID，并遵守各自的工作区全局唯一规则；不自动重分配错误 ID。
- 同一规范化工作区路径只允许一个实例；再次启动在空闲且无保存操作时重载磁盘，再唤醒窗口。`--workspace` 与 `--profile-label` 明确配置边界和界面身份。
- 内容与基线摘要来自同一次读取。保存在锁内规范化副本，用同一份 UTF-8 字节写临时文件并返回摘要，替换前核对预期摘要；失败保留调用方对象与原文件，清理临时文件。
- 首次创建禁止覆盖外部新建文件。已有文件最终校验的只读共享句柄必须在替换前关闭，因此仍有极短竞争窗口；该保护不构成跨程序文件系统事务。
- 外部变化会禁用保存并取消恢复轮次。激活后的异步检查必须核对原基线和当前保存/重载状态，忽略迟到结果；保存层的最终校验独立执行。
- 编辑与确认的模态窗口阻止延迟重载；编辑开始捕获确切对象，保存前重新核对归属、索引和占用，不能因选择变化把草稿写入另一命令。

导入先展示完整预览和冲突范围，确认后只保存，不执行、不探测。保留本机项时保留整套配置；替换时使用导入项整套变量、探测与恢复开关，不隐式沿用旧密文。合并深复制配置，失败恢复原工作区。

导出把敏感项转为待填写，拒绝覆盖当前工作区及目录联接、符号链接别名；同卷手工硬链接仍不能识别。回退使用旧版兼容副本，可分享导出不能代替完整备份。

## 环境变量与脱敏

schema 3–5 的每条命令必须含非 null 的 `EnvironmentVariables` 数组；schema 1/2 缺失时按空数组读取。

| 形状 | 必需字段 | 禁止字段 |
| --- | --- | --- |
| 普通值 | `Name`、`IsSensitive: false`、字符串 `Value` | `ValueState`、`ProtectedValue` |
| 待填写敏感值 | `Name`、`IsSensitive: true`、`ValueState: "Required"` | `Value`、`ProtectedValue` |
| 已保护敏感值 | `Name`、`IsSensitive: true`、`ValueState: "Protected"`、非空 Base64 `ProtectedValue` | `Value` |

变量名不能空白、首尾带空白或含 `=`、NUL，同一命令内不区分大小写判重。值不得含 NUL；普通值和解密后的敏感值允许空字符串，敏感明文最多 4096 个 UTF-16 码元。密文不可解密时保留原数据并阻止启动，不回退为继承环境或空值。

每次启动建立独立环境快照并覆盖继承值，只向目标进程注入，不修改宿主全局环境。DPAPI 使用 `CurrentUser`；编辑器不解密回填，改名或改为普通项需重新提供值，取消与保存失败保留原配置。

stdout/stderr 分别先脱敏再进入界面、内存、复制和磁盘。精确遮蔽本次已知非空敏感值，并补充有界的 `Bearer`、`token=`、`api_key=` 模式。处理块最多 16,384 个 UTF-16 码元，可能匹配的后缀最多保留 4,095 个；模式候选超过 256 个码元持续省略到分隔符，单块模式超时 50 ms。超时、超限或残片无法安全处理时输出固定省略提示，不回退原文。

脱敏不处理旧日志、目标程序另写文件、编码后的秘密或跨通道拆分值；明文与 DPAPI 保护边界见[隐私说明](privacy.md)。

## TCP 探测

仅服务可配置 `TcpProbe`，缺失或 null 表示关闭，保存关闭项时省略。非空对象必须完整包含以下字段；schema 1–3 拒绝非空探测。

| 字段 | 默认值 | 范围 |
| --- | --- | --- |
| `Address` | `127.0.0.1` | 精确为 `127.0.0.1` 或 `::1` |
| `Port` | 必填 | 整数 1–65535 |
| `IntervalSeconds` | 2 | 整数 1–60 |
| `ConnectTimeoutSeconds` | 1 | 整数 1–60 |
| `StartupTimeoutSeconds` | 120 | 整数 1–3600，且不小于连接超时 |
| `FailureThreshold` | 3 | 整数 1–100 |

| 状态 | 含义 |
| --- | --- |
| `NotConfigured` / `Inactive` | 未配置 / 未探测；停止失败且进程存活时显示探测已停止 |
| `Waiting` | 尚无成功且未到启动期限 |
| `Passed` | TCP 可达；阈值内失败仍保留通过并显示失败计数 |
| `TimedOut` | 首次成功前已超过启动期限，继续探测 |
| `Unreachable` | 曾成功，随后连续失败达到阈值；继续探测并可恢复 |

会话创建后立即尝试连接，每次结束再等待间隔，同会话不并发或补发；启动期限独立计时。成功关闭连接、不发送业务数据，清零失败数；首次成功后不再使用启动期限。主动取消不计失败。

停止请求或归属进程组退出即取消探测，不等日志排空；新会话建立新周期，旧回调需核对身份。探测失败不改变进程结果、不触发分组清理或自动重启。项目按唯一命令统计活动会话与当前 Passed 服务；结果只在内存，不写历史日志。TCP 连通不证明业务健康或监听者归属，不能据此接管其他监听者。

## 有限自动重启

schema 5 的 `AutoRestartEnabled` 是服务布尔开关，默认 false，保存 false 时省略；拒绝 null、错误类型、任务上 true，以及旧 schema 中的新字段。旧配置默认关闭，编辑、复制和导入导出保留开关。

仅独立启动（单条或勾选批量）的服务在 `Completion` 正常返回失败及非零退出码后恢复。每轮最多追加 3 次，等待 2/4/8 秒；任务、服务退出 0、分组启动、TCP 失败和日志故障不触发。每次新会话有独立 Job、日志批次、运行版本与探测周期，旧会话归属退出、输出及日志收尾完成后才开始退避。

等待不消费次数；到期通过预检后，在串行提交入口计次并创建。预检或创建失败立即中止本轮，创建失败消费该次尝试；运行时长及 TCP 通过均不重置。新的手动运行/重启成功才获得新预算。次数、截止时间及轮次只在内存，不跨启动恢复。

`CommandRecoveryCoordinator` 统一承接桌面各启动来源，创建/登记与停止/关闭共享串行边界。命令 ID、轮次和会话版本隔离旧回调，每命令最多一条恢复链。观察或创建回滚无法确认归属释放时保留故障占用，手动、批量与分组均不能绕过；仍有控制资源时允许再次停止。

停止或手动重启先取消旧轮次；停止或重启预检失败也不恢复旧等待。等待、提交、收尾和故障归属均参与编辑/删除、导入/重载、日志迁移和退出保护。等待不计入运行/TCP 通过数，单独展示待重试数量；保留上一批次的真实退出码，恢复状态不写入 stdout/stderr 或历史字段。

退出先暂停自动提交，再读取含待重试和未完成回调的快照。返回应用保留原截止时间与预算，已到期最多提交一次；确认退出在首次异步等待前关闭所有启动入口并取消轮次，只等待已提交归属会话停止和日志收尾，不等待退避。停止失败保留窗口及停止入口，旧轮次不恢复。最小化、切页和恢复窗口不改变预算。

每次自动预检从 Dispatcher 取得配置副本，重新验证工作目录、磁盘身份和敏感值；后台不访问绑定对象。保存期间暂停自动提交，结束后保留原截止时间；外部修改取消轮次并禁用新启动。导入预览明确开关、固定预算及分组不生效，读取或确认导入不运行、不探测。

## 日志存储与历史读取

日志按项目、命令、批次 GUID 分层，stdout/stderr 分开保存；元数据含时间、结果及截断/失败状态。重开时未结束批次记为中断。默认每工作区 500 MB、30 天；先清理过期批次，再按时间删除最旧的已结束批次。活动批次受内存 ID 保护，不因元数据损坏被删；只剩活动批次且容量不足时停止后续落盘并提示，命令继续运行。

目录枚举跳过非 GUID 目录及重解析点；损坏、缺失或身份不符的 `run.json` 不列入历史，但计入容量并可清理，排序和期限回退为目录 UTC 修改时间。清空显示不删除文件，删除命令不立即删除历史。

迁移日志要求没有活动批次或待重试；先迁移设置和历史再切换位置，拒绝覆盖已有目标。旧目录删除失败时提示残留路径。

历史读取在后台按长度快照从尾部扫描最近 10,000 行，16 KiB 分块，支持 UTF-8、LF/CR/CRLF。磁盘读取和解码不持有日志写入锁，允许并发追加与删除。切换批次、通道、项目或关闭取消旧请求，回调再次核对身份；超长单行仍须读取其全部字节，文件系统调用和 WPF 排版不能保证立即取消。

## 更新检查

本机版本来自 `InformationalVersion`，渠道来自明确的 `ReleaseChannel`（Stable/Preview）；缺失或无效时禁用检查，不猜测渠道。远端标签接受一个小写 `v` 前缀，按 SemVer 比较并忽略构建元数据；排除草稿，仅稳定渠道还排除预发布标记与后缀，只提示严格更高的最高合格版本。

- 默认关闭，打开页面、切换渠道及本次开启均不联网；开启后下次窗口显示并加载设置后延迟 5 秒尝试，距上次实际尝试至少 24 小时，持续打开不轮询。
- 默认跟随构建渠道，可显式选择稳定版或含预览版。稍后暂停该版本 24 小时，跳过仅抑制该版本；不回退推荐更旧版本。手动检查忽略这些提醒规则，仍遵守节流与限流。
- 匿名 GET 固定仓库 `kongerly/TalosDesk` 的 GitHub Releases 列表，不使用 `/latest`，不发送用户数据、登录令牌或 Cookie。采用系统代理、正常 TLS、固定产品标识及 API 版本头。
- 同源 HTTPS 分页每页 100 条、最多 5 页，总预算 15 秒、解压正文累计最多 5 MiB；拒绝重定向、循环、异常分页和不完整结果，不据部分列表声称无更新。
- 首次请求之间至少 60 秒；403/429 遵守 `Retry-After` 和有效重置时间的最晚期限，无有效头至少等 60 秒，不自动重试。普通频率使用单调时钟，未来缓存时间不无限延后检查。
- 点击才通过浏览器打开 HTTPS `github.com/kongerly/TalosDesk/releases/tag/<合法标签>`，读取缓存与打开前均精确校验主机、端口和单路径段，拒绝额外参数、片段或用户信息；不下载附件或渲染正文。

偏好和缓存按工作区隔离，各自 schema 1，不进入工作区导入导出。ETag 绑定完整请求及页内容，304 仅复用有效匹配缓存；整组分页完整成功才替换旧结果。失败保留带原时间的历史结果，更新尝试与限流记录，不能显示为新结果。

两个文件分别原子保存；写入失败不抹去有效网络结果，本会话偏好和限流仍生效。偏好损坏保留文件、关闭自动并禁止直接覆盖，手动按跟随当前渠道检查；缓存损坏仅放弃缓存。删除后的恢复方式见[隐私说明](privacy.md)。

同实例只保留一个检查任务，手动可接管自动请求，关闭自动不取消手动归属请求。切换渠道取消旧请求并使回调失效；确认退出取消全部请求且不等待网络。错误只显示固定类别，不保存原始响应或底层异常。更新不接管命令，也不阻塞运行和输出。

## 诊断与桌面生命周期

本地诊断按工作区默认开启，可关闭；只保存版本、平台、异常类型、错误码和无源码路径的结构化堆栈。单记录最多 8 个异常节点、4 层、每节点 32 帧、字符串 256 字符、64 KiB；总上限为 100 条、5 MiB、30 天。不递归或跟随重解析点；损坏记录不展示原文，但计入清理。

致命异常无等待重入保护，尽力记录一次后非零退出；未观察任务异常每会话最多记录一次，不改变运行时策略。失败不换目录、不递归记录；强制结束、断电或严重资源故障不保证留下记录。磁盘时间为 UTC，界面按 Windows 本地时区显示，不自动上传。

提示窗口由 WPF 统一提供，正文可滚动复制，确认默认取消/返回，Esc 和关闭走取消，文件选择仍用原生窗口。主窗口正常退出保存独立窗口状态；缺屏或 DPI 变化将位置限制在可见区域，损坏回退默认布局。窄窗口允许滚动、换行及输出命令下拉选择，底部确认按钮保持可达。

托盘注册成功后最小化才隐藏任务栏入口，命令和日志继续运行；恢复保留普通/最大化状态。注册失败保留任务栏，通知区域重建后尝试重新注册，失败恢复窗口。托盘退出与“×”共用退出流程，关闭期间阻止重入；正常退出释放托盘资源，不保存隐藏状态。
