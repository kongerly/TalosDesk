# TalosDesk v0.3.0 稳定版发布说明

TalosDesk v0.3.0 面向 Windows 11 x64，以包含 .NET 10 运行时的便携包发布，构建渠道为 Stable。本版按用户确认的本机审查与隔离回归范围正式发布，未执行的客户端与实机验收继续明确披露。

## 新增与改进

新增服务 TCP 探测与项目汇总。进程运行和端口可连接分别显示；默认 2 秒间隔、1 秒连接超时、120 秒启动等待、连续失败阈值 3 次。可选 `127.0.0.1` 或 `::1`，不支持远程地址。

超时后继续检查并可恢复；通过后的短暂失败在阈值内保留通过并显示失败计数。探测失败不会自动停止或重启，也不触发分组失败清理。TCP 连通不证明业务健康或监听者归属。探测状态仅用于当前运行，不记录到历史日志。

工作区升级为 schema 4，兼容读取 schema 1–3，旧配置默认关闭探测；读取不改写，下次成功保存才升级。旧应用不能读取 schema 4，回退前须准备兼容副本。导入先预览策略，替换采用完整导入配置，不执行命令或探测。

同时包含窗口尺寸与位置恢复、窄窗口与编辑弹窗适配、最小化到系统托盘及统一应用内提示窗口。最小化后命令与日志继续运行，恢复和退出沿用当前工作区的运行管理流程。

工作区读取拒绝未知字段、重复键和全零项目/命令 ID；保存使用实际写入内容的摘要，并检测外部修改，失败时保留原文件及调用方配置。历史日志在后台读取尾部，损坏或缺失元数据的批次仍计入容量并参与清理；同时分组持续监视服务并只清理本次启动的会话。

## 验证范围

完整自动化测试、Release 构建、`scripts/Publish.ps1`、最终 ZIP 的程序集与桌面回归、版本和 SHA-256 一致性、许可与包内数据检查的实际结果见[验收清单](acceptance-v0.3.0.md)。测试只使用临时工作区、合成命令和隔离配置。

## 已知限制

- 未执行本版干净 Windows 11 x64 客户端、系统级丢包下真实挂起连接的超时与取消、多屏/DPI 实机复验，以及真实托盘鼠标点击和资源管理器重建通知区域验收。本机与合成测试不替代这些项目。
- 仅支持无需中途输入的非交互命令；PowerShell 7 必须位于应用继承的 `PATH`，项目自身工具需单独安装。
- TCP 连通只说明所选回环端口可达，不能证明业务健康或监听者归属；探测失败不自动停止或重启命令。
- 工作区保存后为 schema 4，旧应用不能读取；回退须使用旧版兼容副本。已有文件最后校验与替换之间仍有极短竞争窗口。
- 便携包未签名；SHA-256 校验只验证文件完整性，不能替代发布者签名。Windows 10、安装程序、自动重启、多 Shell、HTTP 检查和服务依赖编排不在本版范围。

下载 [v0.3.0 发布附件](https://github.com/kongerly/TalosDesk/releases/tag/v0.3.0)中的 ZIP 与同名 `.sha256` 文件，核对后完整解压到新的应用目录，再运行 `TalosDesk.App.exe`。升级前停止命令、退出旧版并备份本机工作区、日志及所需旁文件，不覆盖正在运行的程序。
