# TalosDesk 路线图

TalosDesk 聚焦 Windows 本地多项目、非交互命令的运行管理。版本号表示规划方向，具体范围会随用户反馈和验证结果调整，不承诺日期。

## 当前版本

- 已发布的稳定版是 v0.3.0（schema 4），提供服务 TCP 探测、项目汇总、托盘和窗口恢复，详见[版本记录](changelog/README.md)。
- 当前源码为 v0.3.1-rc.1 / Preview（schema 5），加入了默认关闭的[服务有限自动重启](design.md#有限自动重启)，尚未发布。
- 历史包的运行时安全基线和替代版本状态见[安全维护说明](security-maintenance-2026-10-22.md)。

## 后续方向

下表每一行是一个候选方向。“范围与准入条件”是开始实现前必须先证明的事情，不是已经排期的计划。

| 方向 | 范围与准入条件 |
| --- | --- |
| Windows 多 Shell | 先支持 Cmd，再评估 Git Bash。每种 Shell 都要独立验证引用、编码、中文/空格路径、子进程、Ctrl+C 与强停 |
| 探测与日志搜索 | 按需求分别评估 HTTP、日志关键字探测和当前日志搜索。跨批次索引要先验证存储、脱敏与性能成本 |
| WSL | 先证明归属和清理边界，不把终止共享发行版当作普通停止策略 |
| 客户端兼容 | 只有在具体的 Windows、补丁与依赖组合上完成完整操作验收后，才扩展支持声明 |
| 分发 | 评估代码签名与包管理器的维护成本，完善升级、备份和恢复说明 |
| v1.0.0 | 核心启动/停止和数据迁移没有已知阻塞缺陷，声明支持的客户端有可复现验收，分发与贡献文档完整 |

交互式终端、跨平台、后台服务器、云账号、插件市场、内存阈值重启和静默更新暂无交付承诺。多 Shell、WSL 和跨平台不是 v1.0.0 的必选条件。

## 参与开发

每次改动围绕一个可验证的主题，优先复用现有的进程归属、配置预览和日志机制，不预建未确认的抽象。新增平台或 Shell 必须先证明停止和异常清理的边界。实现契约见[设计说明](design.md)，开发约定见[贡献指南](../CONTRIBUTING.md)，验证方法见[测试说明](testing.md)。
