# TalosDesk 发布路线图

## v0.1.0 公开预览

`v0.1.0` 已具备项目与命令管理、运行和停止、批量启动、实时输出、配置持久化及 JSON 导入导出能力。核心进程管理和配置异常路径已有自动化测试，桌面界面也完成了隔离配置下的回归检查。

公开预览版的完成条件：

- [x] 合成命令覆盖成功、失败、停止、强制停止、重启、并发和大量输出。
- [x] 同一命令不能重复运行，不同项目的命令可以同时运行。
- [x] 每次运行只保留最近 10,000 行输出。
- [x] 配置损坏、保存失败和导入冲突不会静默覆盖原配置。
- [x] 命令支持编辑、复制、删除、排序和批量启动；命令卡片支持双击编辑和鼠标拖动排序。
- [x] 自包含 Windows x64 发布目录可以启动。
- [x] 命令编辑和导出流程明确提示明文配置风险。
- [x] 提供统一的 Release 构建、测试、打包和校验脚本。
- [x] 最终候选包在本机 Windows 11 x64 的隔离配置和无 SDK 路径环境下启动并正常退出。
- [x] 在独立工具目录完成三轮服务启动、健康检查、短推理、停止及端口释放验收。
- [x] 当前候选工作树、图片和本地发布包完成隐私检查。
- [x] 新建公开仓库后再次检查提交作者、提交历史和远端内容。
- [x] 从干净快照建立公开仓库并创建 `v0.1.0` Pre-release。

干净 Windows 11 机器验收不作为 v0.1.0 公开预览的发布阻塞项，留待发布后补充。

## v0.1.0 不包含

- 安装程序和自动更新。
- 代码签名。
- 后台托盘运行。
- 自动扫描项目或推荐命令。
- 交互式终端、服务就绪探测和持久化日志。
- Windows 11 x64 以外平台的兼容承诺。

后续功能根据公开预览反馈决定，不提前承诺版本或时间。

## v0.1.0 之后的当前开发分支

- [x] 命令可复用于多个项目内分组，分组支持同时执行或仅任务可用的按成功顺序执行。
- [x] 工作区 schema 2 保存分组和成员顺序，并兼容读取 schema 1。
- [x] 分组编排、配置校验和桌面执行路径具备隔离测试。
- [x] 同时分组会监督运行期失败，停止本分组启动的其他命令并给出明确提示。
- [x] 运行输出区区分诊断通道与失败状态，并支持终端式范围选择、`Ctrl+C` 和右键复制。
- [x] 命令编辑器支持 PowerShell 语法着色、多行缩进、成对符号，以及路径、可执行程序和环境变量的安全补全。
