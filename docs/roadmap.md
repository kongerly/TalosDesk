## 3. 已确认的推进顺序

### 第一步：验证命令执行与进程管理

目标：打通“启动 → 获取日志 → 停止及子进程清理”。

先使用独立临时目录和可控测试程序验证普通退出、失败、大量输出和子进程场景。
在得到真实项目运行授权后，验证 go run、uv 等启动方式的实际表现。
命令通过 PowerShell 7 `-NoProfile -NonInteractive` 执行；停止先发送 Ctrl+C，等待 5 秒后强制清理归属进程。每个命令最多保留最近 10,000 行内存日志，同一命令不可重复启动，不同命令可并行。

验收重点：

- [x] 合成命令的工作目录正确，标准输出和错误输出均可读取，退出码对应成功或失败状态。
- [x] 合成命令支持 Ctrl+C 停止；忽略 Ctrl+C 的跨控制台子进程会在 5 秒后由进程组强制清理。
- [x] 同一命令不可重复启动，不同命令可以并行；日志保留最近 10,000 行。
- [x] 合成测试覆盖启动失败后的重试、CreateProcess 失败时的资源回收、同一命令停止后重启、强制停止调用失败后保留原会话并重试、强制停止后的退出确认超时、输出订阅回调异常，以及自然结束和失败退出状态。
- [x] 自动化测试覆盖进程运行管理与配置文件读写规则。

阶段结果应明确支持范围与尚未验证的情况，未验证的启动器不能宣称已兼容。

### 第二步：完善界面与配置

目标：形成用户可以直接操作的项目与命令工作台。

验收重点：

- [x] 已提供添加、查看、编辑项目及添加、编辑、复制命令的入口；桌面验收确认编辑项目名称和目录后能保存，并将项目内相对工作目录随目录迁移。
- [x] 配置可保存、导入、导出；导入预览后逐项处理冲突，不自动执行命令。
- [x] 两个项目的合成服务可同时运行；切换项目不停止服务，各命令日志分别展示。
- [x] 界面显示开始时间、运行状态和退出结果；大量输出时仍能切换项目并停止任务。
- [x] 有任务运行时关闭应用会提供停止并退出或返回应用的选择；停止异常时窗口保持打开并提示。
- [x] 损坏的本机配置会显示中文错误并保持原文件不变；导入预览能识别项目和命令冲突，保留本机版本后导入的新增命令不会自动执行。
- [x] 新增项目遇到保存失败会回滚，错误状态在提示关闭后仍保留。
- [x] 命令添加或编辑遇到保存失败时会回滚；桌面验收确认新增命令不会残留，编辑命令恢复原内容，提示关闭后仍显示“保存失败”。
- [x] 命令可确认后删除并上移、下移调整保存顺序；运行中的命令不可删除，保存失败时删除和排序都会回滚。
- [x] 勾选当前项目中任意多条命令后可同时启动尚未运行的命令；两条合成长任务在界面上同时显示运行中，结果分别查看。

## 4. 首版完成标准

用户能够保存自己的项目命令，在以后重新打开应用时直接运行，清楚看到执行结果，并可靠停止受管理的任务。
核心异常路径有自动化验证，桌面操作和真实项目行为有试用记录，发布包可重复构建与启动。
功能验收未完成时不标记首版完成；不把存在测试文件当作测试已经通过。
