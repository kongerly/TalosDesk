# 运行时安全维护说明

更新日期：2026-10-22。

结论：v0.1.0 到 v0.3.0 的历史自包含包仍在使用 .NET 10.0.12，请停止继续分发。本地重建已经完成，但尚未发布。

## 对使用者的影响

经本地核实，v0.1.0、v0.1.1、v0.2.0、v0.3.0-preview.1 和 v0.3.0 的历史自包含包都嵌入了 .NET / Windows Desktop 10.0.12。这些包使用包内运行时，更新系统 .NET 不会替换它。

[Microsoft .NET 10 发布元数据](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json)把 2026-10-13 的 10.0.13 标记为安全更新，配套 SDK 为 10.0.402。本说明只核实组件基线，不声称每个 .NET 漏洞都能通过 TalosDesk 触发。

## 修复与分发状态

- 当前源码已固定 SDK 10.0.402、自包含运行时和 ProtectedData 10.0.13。
- 当前 rc.1 和基于 v0.3.0 的稳定版维护副本都已完成本地重建，但尚未发布；历史远端附件没有替换，不能视为已经修复。
- 稳定版维护副本仍有默认并发下的日志迁移测试失败；单工作线程全量通过，不等于该问题已经消失。
- 新重建产物尚未完成最终 EXE 的完整人工操作链，也还没有验证干净客户端、跨账户 DPAPI、多屏/DPI、真实托盘和通知区域重建。包内程序集测试和截图不能替代这些检查，产物仍未签名。

运行时更新不改变应用功能或配置格式：v0.3.0 维护副本保留 schema 4，rc.1 使用 schema 5。维护包不能读取 schema 5，因此不能作为它的直接回退方案。rc.1 也不会因为运行时更新而成为正式版。同版本只增加 SemVer 构建元数据不会触发更新提示，正式分发必须使用明确的版本与渠道。

可用的替代版本将列在[官方发布页](https://github.com/kongerly/TalosDesk/releases)。更换应用前，先停止命令、退出应用，并备份完整工作区及所需旁文件，再把新包解压到新目录。可分享导出不含敏感值，不能代替完整备份。操作步骤见 [README](../README.md#手工升级)。
