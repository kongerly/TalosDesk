# 运行时安全维护说明

更新日期：2026-10-22。

结论：v0.1.0 到 v0.3.0 的历史自包含包仍在使用 .NET 10.0.12，请停止继续分发。本地重建已经完成，但尚未发布。

## 对使用者的影响

经本地核实，v0.1.0、v0.1.1、v0.2.0、v0.3.0-preview.1 和 v0.3.0 的历史自包含包都嵌入了 .NET / Windows Desktop 10.0.12。这些包使用包内运行时，更新系统 .NET 不会替换它。

[Microsoft .NET 10 发布元数据](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json)把 2026-10-13 的 10.0.13 标记为安全更新，配套 SDK 为 10.0.402。本说明只核实组件基线，不声称每个 .NET 漏洞都能通过 TalosDesk 触发。

## 修复与分发状态

- 当前源码已固定 SDK 10.0.402、自包含运行时和 ProtectedData 10.0.13。
- 当前 rc.1 和基于 v0.3.0 的稳定版维护副本都已完成本地重建，但尚未发布；历史远端附件没有替换，不能视为已经修复。
- 后续隔离调查已在 rc.1 复现同一迁移问题，且不加载 TalosDesk、不并行测试的嵌套目录复制/重命名也可触发 Windows 错误 5，短暂等待后可成功。具体占用来源尚未确认，不能归因为测试隔离或特定安全软件。当前源码与 schema 4 维护副本已加入有界重试及持续失败/目标冲突回归；单工作线程通过不再作为修复依据。
- 修复后的两个副本已通过默认并发完整测试、Release 构建及本地打包。rc.1 稳定化 ZIP 已补测成功/失败、运行/停止/强停、分组、有限重启耗尽、日志迁移及强制结束后的归属清理和中断历史。后续 schema 6 开发包另已复核日志搜索、Cmd 双通道/强停、默认 PowerShell，以及等待中退出确认的暂停、返回保留预算和确认退出取消等待；最后一次确认由用户点击，退出后核对没有新建会话或残留归属子进程。等待中直接点击“停止”仍只由包内 WPF 回归覆盖，schema 4 维护包也尚未执行完整 EXE 操作链。干净客户端、跨账户 DPAPI、多屏/DPI、真实托盘鼠标和通知区域重建仍未验证，产物仍未签名。

运行时更新本身不改变应用功能或配置格式：v0.3.0 维护副本保留 schema 4，稳定化阶段的 rc.1 产物使用 schema 5。之后的 Windows Cmd 开发改动另将工作源码升级到 schema 6；维护副本不包含日志搜索或 Cmd。schema 4 维护包不能读取 schema 5/6，此前 schema 5 的 rc.1 也不能读取 schema 6，回退必须使用兼容备份。应用版本号和渠道尚未为这些新增改动重新分配，本地开发包不能直接作为正式版本分发。同版本只增加 SemVer 构建元数据不会触发更新提示，正式分发必须使用明确的版本与渠道。

可用的替代版本将列在[官方发布页](https://github.com/kongerly/TalosDesk/releases)。更换应用前，先停止命令、退出应用，并备份完整工作区及所需旁文件，再把新包解压到新目录。可分享导出不含敏感值，不能代替完整备份。操作步骤见 [README](../README.md#手工升级)。
