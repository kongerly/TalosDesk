# 常见问题

以下按使用顺序整理常见问题。每条先给结论，再说明原因。

## 最小化后在哪里找回窗口？

v0.3.0 起，主窗口最小化后会收起到 Windows 右下角的系统托盘，命令与日志继续运行。图标可能位于通知区域的折叠菜单中：左键单击恢复，右键菜单可以选择“显示主窗口”或“退出”。恢复时会保留之前的普通或最大化状态。右上角的“×”仍然退出应用，有运行中任务时会先确认；取消退出或停止失败后，窗口保持打开。

## 为什么命令显示“运行中”，服务却还不能访问？

“运行中”只表示进程仍然存在。v0.3.0 起，可以在服务编辑器中开启本机 TCP 探测：加载期间显示“等待中”，端口可以连接后显示“TCP 探测通过”。旧配置默认关闭。

TCP 能连接不代表业务健康，也不能确认监听者属于该命令；被其他程序占用的端口也可能通过。启动等待超时后仍会继续探测，并且可以恢复；运行中连续失败达到阈值才显示不可达，阈值内的失败仍计入通过并显示失败计数。探测失败不会停止或重启服务，历史批次不保存探测状态。

## stderr 是否表示运行失败？

不是。TalosDesk 会把 stderr 分开展示，但最终状态以进程退出结果和退出码为准。

## 为什么敏感变量换账户后无法使用？

敏感值使用 Windows DPAPI `CurrentUser`，只能由保存它的账户解密。请在目标账户重新录入；可分享导出不会携带密文。

## 导入示例会运行命令或安装依赖吗？

不会。导入总是先展示预览，确认后只保存配置。运行仍需要用户主动操作，示例也不会安装工具。

## 崩溃诊断包含什么？会上传吗？

诊断只包含版本、平台、异常来源、异常类型、错误码，以及去掉源码路径的结构化堆栈。它不包含异常消息、命令、输出、环境变量或凭据，也不会自动上传。可以在“关于与更新”页查看、关闭或清理。

## 为什么崩溃后没有记录？

参数解析前、强制结束、断电、栈溢出、严重内存故障、磁盘不可写或文件系统阻塞都可能阻止记录。诊断是尽力而为，不是内存转储。

## 更新检查会自动安装吗？

不会。自动检查默认关闭；检查只读取官方 GitHub Releases 元数据。TalosDesk 只在用户点击后打开经过校验的发布页，不下载或替换程序。
