# 常见问题

## 为什么命令显示“运行中”，服务却还不能访问？

“运行中”只表示进程仍存在。v0.2.0 不提供服务就绪探测，请查看命令输出或使用项目自己的健康检查。

## stderr 是否表示运行失败？

不是。TalosDesk 分开展示 stderr，但最终状态以进程退出结果和退出码为准。

## 为什么敏感变量换账户后无法使用？

敏感值使用 Windows DPAPI `CurrentUser`，只能由保存它的账户解密。请在目标账户重新录入；可分享导出不会携带密文。

## 导入示例会运行命令或安装依赖吗？

不会。导入总是先展示预览，确认后只保存配置。运行仍需用户主动操作，示例也不会安装工具。

## 崩溃诊断包含什么？会上传吗？

诊断只包含版本、平台、异常来源、异常类型、错误码和无源码路径的结构化堆栈。它不包含异常消息、命令、输出、环境变量或凭据，也不会自动上传。请在“关于与更新”页查看、关闭或清理。

## 为什么崩溃后没有记录？

参数解析前、强制结束、断电、栈溢出、严重内存故障、磁盘不可写或文件系统阻塞都可能阻止记录。诊断是尽力而为，不是内存转储。

## 更新检查会自动安装吗？

不会。自动检查默认关闭；检查只读取官方 GitHub Releases 元数据。TalosDesk 只在用户点击后打开经过校验的发布页，不下载或替换程序。
