从最终 ZIP 解压到独立临时目录，所有启动均显式指定临时工作区与验收标识。未使用用户真实项目或工作区。最终包交互结果：

| 路径 | 实际结果 |
|---|---|
| 合成服务启动但未监听 | 等待中 → 启动等待超时，进程继续运行 |
| 创建/撤销合成监听器 | 探测通过 → TCP 不可达 → 恢复通过，未自动停止或重启 |
| 项目统计 | 一个活动服务显示运行 1、探测通过 1 |
| 重启 | 新批次先等待，再通过，输出属于新批次 |
| 并发 | 服务运行期间成功任务完成，退出码 0 |
| 普通停止 | TCP 服务撤销通过并停止；退出码按实际进程结果显示 |
| 强制停止 | 显式忽略 Ctrl+C 的合成服务最终显示已强制停止；另一 TCP 服务保持运行 |
| 同时分组失败 | 合成任务退出码 7，只清理本次分组启动的服务 |
| 顺序分组 | 成功任务退出码 0 后执行失败任务，退出码 7 |
| 导出/导入预览 | 导出为 schema 4，六个探测字段完整；预览展示策略及替换关闭提示，取消后原工作区保留 |
| 编辑器往返 | 改端口后取消，重开仍为原值；保存后重开显示新值；关闭探测后 JSON 省略字段；服务切换任务提示移除并在保存后省略字段 |
| 保存失败保护 | 仅向临时工作区追加空行制造外部改写；编辑保存被拒绝，文件 SHA-256 与原探测端口保持不变，重开后原配置可继续编辑 |
| 异常关闭 | 核对可执行文件路径后强制结束本次测试宿主；归属监听端口释放，重开后旧批次为 Interrupted，运行数量为 0 |
| 日志初始化失败 | 用普通文件阻塞临时日志目录；明确提示日志未保存，服务仍可运行、探测通过并停止 |

异常关闭验证的是强制结束宿主，未模拟系统断电；日志失败验证的是目录初始化失败，未在最终包中模拟磁盘写满。验收进程已退出。
