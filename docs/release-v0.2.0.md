# TalosDesk v0.2.0 稳定版发布说明

TalosDesk v0.2.0 面向 Windows 11 x64，以包含 .NET 10 运行时的便携包发布。本版在 v0.1.1 的项目运行、分组、日志与敏感环境变量能力上，补充更新检查、本地崩溃诊断和维护材料。

## 新增与改进

- “关于与更新”页提供手动更新检查及可关闭的启动检查，只读取经过限制和校验的官方 GitHub Releases 元数据。
- 新增按工作区隔离的本地崩溃诊断，默认开启，可查看、关闭和清理；不生成内存转储，也不自动上传。
- 崩溃记录只含版本、平台、异常类型、错误码和无源码路径的结构化堆栈；不保存异常消息、命令、输出、环境变量或凭据。
- 诊断文件继续使用 UTC 时间，界面按当前 Windows 时区显示简洁本地时间。
- 命令启动错误使用固定中文提示，PowerShell 输出以纯文本捕获；日志入口及不可用警告在最小窗口宽度下仍可见。
- 增加贡献指南、隔离测试说明、缺陷模板、FAQ 和三个可预览导入的 schema 3 示例工作区。

## 数据与联网

诊断记录位于 `<工作区文件路径>.crashes`，最多保留 100 条、5 MiB 和 30 天；开关位于 `<工作区文件路径>.diagnostics-settings.json`。两个位置均不进入工作区导入导出或发布包。诊断不会联网。更新检查默认关闭，详细边界见[隐私说明](privacy.md)。

## 验证结果

- 全新 Windows 11 x64 环境完成启动、成功/失败命令、长运行服务、停止与强停、分组失败清理、日志迁移与异常、导入预览、崩溃诊断和退出确认。
- 两个独立 Windows 账户完成 DPAPI 往返验收：跨账户密文保持不可解密，重新录入后可运行，工作区、日志与导出未发现合成敏感明文。
- 真实 GitHub 手动检查成功并正确返回无更新；当时没有更高官方版本，因此默认浏览器真实候选页点击不适用，URL 校验和浏览器调用由自动化替身测试覆盖。
- R6 虚拟机验收后的本地时间显示调整仅涉及显示层；按验收约定完成本机定向测试、完整自动化测试、Release 构建和发布脚本验证，没有重制虚拟机介质。
- `scripts/Publish.ps1` 完成还原、Release 构建、完整自动化测试和自包含发布；构建 0 警告、0 错误，测试 0 失败、0 跳过。当次的用例通过数量见[变更记录归档](changelog/implementation-log-v0.1.1-to-v0.2.0.md#t08-本地实施记录2026-09-29)。
- `TalosDesk-v0.2.0-win-x64.zip` 未发现工作区、运行日志、崩溃记录、诊断设置、测试结果、测试宿主或 PDB。
- ZIP 校验值以 [`v0.2.0` 发布附件](https://github.com/kongerly/TalosDesk/releases/tag/v0.2.0)随附的 `.sha256` 文件为准，本说明不重复记录易变的大小与摘要。程序文件版本为 0.2.0.0，产品版本为 0.2.0，构建渠道为 Stable，签名状态为未签名。

## 已知限制

- 仅支持 Windows 11 x64，运行项目命令需要 PowerShell 7 位于 `PATH`；其他项目工具需自行安装。
- 发布包未签名，SHA-256 只能验证文件完整性，不能替代发布者签名。
- 仅支持无需中途输入的非交互命令；“运行中”只表示进程存活，不表示服务已经就绪。
- 参数解析前、强制结束、断电、栈溢出和严重内存故障可能没有诊断记录。
- Windows 10、安装程序、应用内自动安装更新、代码签名和包管理器分发不在本版范围。

下载 ZIP 后核对同名 `.sha256` 文件，完整解压到新的应用目录，再运行 `TalosDesk.App.exe`。升级前请停止命令、退出旧版并备份本机工作区及需要保留的日志和旁文件；不要覆盖正在运行的程序。
