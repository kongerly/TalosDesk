# TalosDesk v0.2.0 候选说明

状态：本机候选包已生成，尚未发布。

## 主要变化

- “关于与更新”页提供手动更新检查及可关闭的启动检查，只读取经过限制和校验的官方 GitHub Releases 元数据。
- 新增按工作区隔离的本地崩溃诊断，默认开启，可查看、关闭和清理；不生成内存转储，也不自动上传。
- 崩溃记录只含版本、平台、异常类型、错误码和无源码路径的结构化堆栈；不保存异常消息、命令、输出、环境变量或凭据。
- 增加贡献指南、隔离测试说明、缺陷模板、FAQ 和三个可预览导入的 schema 3 示例工作区。

## 数据与联网

诊断记录位于 `<工作区文件路径>.crashes`，最多保留 100 条、5 MiB 和 30 天；开关位于 `<工作区文件路径>.diagnostics-settings.json`。两个位置均不进入工作区导入导出或发布包。诊断不会联网。更新检查默认关闭，详细边界见[隐私说明](privacy.md)。

## 候选限制

- 包仍未签名，SHA-256 只能验证文件完整性，不能替代发布者签名。
- 干净 Windows 11 客户端和跨账户 DPAPI 尚无可用环境，必须保留为候选验收阻塞项。
- 参数解析前、强制结束、断电、栈溢出和严重内存故障可能没有诊断记录。
- Windows 10、安装程序、自动安装更新、代码签名和包管理器分发不在本候选范围。
