# TalosDesk v0.1.1 公开预览版

TalosDesk v0.1.1 面向 Windows 11 x64，继续提供包含 .NET 10 运行时的便携包。本版本在 v0.1.0 的项目与命令运行基础上，补充命令分组、磁盘日志、编辑体验和敏感环境变量保护。

## 新增与改进

- 项目内命令分组支持同时执行，以及任务命令按成功结果顺序执行；分组失败会停止本次分组启动的其他成员。
- 运行输出按项目、命令和批次写入 stdout、stderr 与元数据文件；可设置容量、期限和工作区专属日志位置，并在界面查看或清理历史批次。
- 命令编辑器增加 PowerShell 语法着色、多行缩进、成对符号，以及不会执行输入内容的路径、程序和环境变量补全。
- 输出区支持按字符和跨行选择，使用 `Ctrl+C` 或右键复制，并在选择内容或滚离底部时暂停自动跟随。
- 同一工作区只允许一个实例持有；重复启动会唤醒已有窗口。检测到配置被外部修改时会停止旧窗口继续保存。

## 敏感环境变量

- 命令可配置普通或敏感环境变量。敏感值使用 Windows DPAPI `CurrentUser` 保护，只在启动目标进程前解密，并通过该次进程的独立环境块注入。
- 已保存敏感值不会解密回填到编辑器；界面只显示待填写、已保存或不可解密状态。待填写和不可解密状态会在创建日志或目标进程前阻止启动。
- 可分享导出会移除所有本机敏感密文，只保留变量名和待填写状态。导入始终先展示完整预览，不会自动运行命令。
- 本次运行已知的非空敏感值，以及有限的 `Bearer`、`token=` 和 `api_key=` 模式，会在进入界面、内存和磁盘日志前遮蔽。

## 配置升级

工作区 schema 已升级到版本 3。应用兼容读取 schema 1 和 2，并只在下一次成功保存时升级；读取本身不会改写原文件。旧版本应用应拒绝 schema 3，回退旧包时不要让旧程序覆盖新配置。

DPAPI `CurrentUser` 密文仅适用于当前 Windows 用户，不能作为跨账户或跨设备凭据格式。导入到其他账户后，需要重新填写敏感值。

## 隐私与限制

- 项目路径、命令、用途、分组和普通环境变量仍以明文保存并进入导出文件。请勿把凭据写入命令或普通变量。
- 既有历史日志不会自动改写，仍可能包含敏感内容。脱敏不保证识别编码后的值、拆到 stdout/stderr 两个通道的值或目标程序自行写入其他文件的内容。
- TalosDesk 当前没有账号、云同步、遥测、更新检查或自动上传功能。详细数据位置和清理方法见[隐私说明](privacy.md)。
- 仅支持不需要中途输入的非交互命令；“运行中”只表示进程仍存在，不表示服务已经就绪。
- 本预览版没有代码签名，Windows 可能显示信誉或安全提示；它是便携包，不含安装程序、后台托盘或自动更新。

## 使用要求

- Windows 11 x64。
- PowerShell 7 已安装，且 `pwsh.exe` 位于 `PATH` 中。
- 解压全部文件后运行 `TalosDesk.App.exe`；发布包已经包含 .NET 10 和 Windows Desktop 运行时。

下载后可使用随发布提供的 `.sha256` 文件校验 ZIP 完整性。SHA-256 用于检查文件完整性，不能替代发布者签名。
