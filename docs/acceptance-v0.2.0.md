# v0.2.0 候选包验收清单

所有路径和秘密均使用合成值。每次验收记录 Windows 构建、账户、PowerShell 版本、候选 ZIP 的 SHA-256、通过/失败和证据位置；证据不得进入仓库。

## 干净 Windows 11 x64

- 核对 ZIP 的 SHA-256，在新目录完整解压，以显式 `--workspace <临时路径>` 和 `--profile-label 隔离验收` 启动。
- 验证成功、失败、并发、停止、Ctrl+C 超时强停、重启、顺序/同时分组、历史日志和应用退出。
- 验证导入三个 `examples` 文件时先显示完整预览且不运行、不安装任何依赖；待填写敏感变量阻止启动。
- 验证更新检查的真实 GitHub 成功或可理解失败，以及只有点击后才由默认浏览器打开官方发布页。
- 验证诊断默认开启、关闭后不新增记录、已有记录仍可查看、损坏记录不显示原文、清理确认和目录不可写提示；记录时间在界面按当前 Windows 本地时区显示，页面说明时间来源，磁盘字段保持 UTC。
- 触发隔离测试宿主的 UI 与后台异常，确认应用非零退出、至多一条致命记录，并且本实例拥有的命令进程随 Job 关闭。

## 双账户 DPAPI

1. 账户 A 在临时工作区保存合成敏感变量，重新打开并运行，确认只显示状态且输出已脱敏。
2. 退出后仅将该临时工作区复制给账户 B；不要复制真实工作区或凭据。
3. 账户 B 打开后确认密文原样保留但不可解密，命令不启动，错误不含密文或明文。
4. 账户 B 重新录入另一合成值后运行，确认新值仅在账户 B 可用；导出仍只含待填写状态。

实际结果和证据保存在仓库外的当次验收记录中；任何未完成项目都必须明确标记，不能用本机启动或自动化测试替代。
