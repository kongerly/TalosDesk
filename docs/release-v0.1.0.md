# TalosDesk v0.1.0 公开预览版

TalosDesk v0.1.0 提供 Windows 11 x64 便携包，用于保存和运行本地项目的常用非交互命令，并集中查看状态和输出。

## 主要能力

- 管理项目和任务或服务命令。
- 运行、停止、重启及批量启动命令。
- 在项目之间切换，同时保留本次会话的运行状态和日志。
- 保存、导入和导出工作区配置。
- 同一工作区只打开一个实例，重复启动会唤醒原窗口；侧栏显示实际配置路径。
- 通过 Windows Job Object 管理当前应用启动的归属进程。

## 使用要求

- Windows 11 x64。
- PowerShell 7 已安装，且 `pwsh.exe` 位于 `PATH` 中。
- 解压全部文件后运行 `TalosDesk.App.exe`。

发布包包含 .NET 10 运行时，不需要安装 .NET SDK。目标项目使用的其他开发工具需要单独安装。

发布候选版本已在 Windows 11 x64 本机使用隔离配置启动，并通过三轮本地模型服务启动、健康检查、短推理、停止及端口释放验收。干净机器验收将在公开预览后继续补充。

## 隐私与已知限制

- 工作区和导出文件以明文保存项目路径与完整命令，请勿直接写入密钥。
- 分享导出文件前请先检查内容。
- 每次运行只保留最近 10,000 行内存日志。
- “运行中”不代表服务已就绪。
- 仅支持非交互命令。
- 本版本未进行代码签名，Windows 可能显示信誉或安全提示。
- 本版本是便携预览包，不含安装程序、后台托盘和自动更新。

下载后可使用随发布提供的 `.sha256` 文件校验 ZIP 完整性。
